# Where the business photos go

Drop real photos from Umesh Cleaning Services jobs into this folder. Until a file
exists, the site shows a labelled "Photo needed" placeholder rather than a stock
photo, so no stock image is ever passed off as the business's own work.

Gallery and Before/After photos are NOT stored here — the owner uploads those
through the admin panel so they can be changed without a redeploy.

Photo tips: shoot in landscape, use daylight where possible, and for before/after
pairs shoot from the same spot and angle both times.
